
## 1. Краткое описание выполненной работы

Реализован статический одностраничный лендинг платформы **Cнэпбилд** — сервиса для создания маркетинговых материалов на основе дизайн-системы. Проект собран на Next.js с экспортом в статические файлы и деплоем на GitHub Pages.

В рамках задания воспроизведена структура и визуальная стилистика оригинального сайта, а также добавлены **5 новых секций**, которых нет на исходной странице: сценарии использования по командам, сравнительная таблица, блок метрик, отзывы клиентов и форма запроса демо.

Помимо секций реализованы: адаптивная шапка с мобильным меню, cookie-баннер, UI-kit переиспользуемых компонентов, анимации появления при скролле и CI/CD для автоматической публикации.

## 3. Инструкция по локальному запуску

**Требования:** Node.js 24+, npm

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd next-project-landing

# Установить зависимости
npm ci

# Запустить dev-сервер
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

**Сборка и предпросмотр production-версии:**

```bash
npm run build
npm run preview
```

**Линтинг:**

```bash
npm run lint
```

## 6. Как анализировалась стилистика исходного сайта

1. **Визуальный аудит оригинала** — изучены цветовая палитра, типографика, радиусы скругления, тени и градиенты на оригинальном ресурсе
2. **Design tokens** — вынесены в `src/styles/tokens.scss`: нейтральная база (`#f5f5f6`, `#000`, `#5a5b62`), фирменный градиент оранжевый → розовый → фиолетовый (`#ff6d3c` → `#ff6ba7` → `#bb6dff`), fluid-единица `dpx` для адаптивных отступов.
3. **Типографика** — подключен шрифт TT Commons Pro (веса 300–700), воспроизведена шкала заголовков (h1 ≈ 76dpx, h2 ≈ 52dpx) и отрицательный letter-spacing.
4. **Компонентный разбор** — карточки с градиентной обводкой (`GradientBox`), кнопки с shimmer-эффектом, табы, аккордеон FAQ, переключатель тарифов — сверены с оригиналом по пропорциям и поведению.
5. **Адаптив** — breakpoints для mobile (≤767px), tablet (≤1023px), desktop (≥1024px); проверка на узких экранах и широких мониторах (до 2560px).
6. **DevTools** — через инспектор уточнены spacing, z-index слоёв (header, cookie banner), scroll-поведение и sticky-элементы.

## 10. Какие AI-инструменты использовались и для каких задач

| Инструмент | Задачи |
|------------|--------|
| **Cursor (AI-агент)** | Генерация компонентов, UI-kit, SCSS-модулей, настройка Next.js static export и GitHub Actions |
| **Cursor Chat** | Рефакторинг, исправление багов, дополнение контента в `content.ts`, консультации по Motion API |
| **Context7 MCP** | Актуальная документация Next.js 16 и Motion при работе с нестандартными API |
| **AI-ассистент (Claude)** | Структура проекта, design tokens, текст секций на русском, README |

AI использовался как **ускоритель разработки**: каркас и boilerplate генерировались автоматически, финальная стилизация, контент и интеграция секций дорабатывались вручную с проверкой в браузере.
